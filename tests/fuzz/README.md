# Fuzz Testing in libhisto

`libhisto` contains 14 specialized fuzz targets designed to continuously exercise input parsers, numerical algorithms, wire format deserializers, differential SIMD equivalence, and serialization idempotence.

---

## Fuzz Targets Overview

| Target | Target Area | Description |
|---|---|---|
| `fuzz_deserialize_binary` | Serialization | 1D Canonical Little-Endian binary format deserializer |
| `fuzz_deserialize_json` | Serialization | 1D JSON format deserializer |
| `fuzz_deserialize_2d_binary` | Serialization | 2D Canonical Little-Endian binary format deserializer |
| `fuzz_deserialize_2d_json` | Serialization | 2D JSON format deserializer |
| `fuzz_sketch_binary` | DDSketch | DDSketch quantile sketch binary format deserializer |
| `fuzz_roundtrip` | Serialization | Wire format roundtrip idempotence across 1D, 2D, and sketches |
| `fuzz_fill` | Numerical Engine | Streaming and batch floating-point sample ingestion |
| `fuzz_fit` | Numerical Engine | Levenberg-Marquardt curve fitting across all models |
| `fuzz_kde` | Numerical Engine | Kernel density estimation and bandwidth selectors |
| `fuzz_auto_bin` | Numerical Engine | Automated binning algorithms (Freedman-Diaconis, Scott, etc.) |
| `fuzz_simd_diff` | SIMD Optimization | Differential scalar vs. AVX2/AVX-512/NEON equivalence |
| `fuzz_bpftrace` | Input Parsers | Bpftrace and BCC textual histogram table parser |
| `fuzz_cli_opt` | Input Parsers | Table-driven CLI argument tokenizer and option parser |
| `fuzz_tui_command` | Interactive TUI | Interactive command prompt parsing and engine mutations |

---

## Running Fuzz Tests

### Standalone Regression Suite

The standalone regression suite executes all seed corpus files across all 14 targets without requiring Clang's `-fsanitize=fuzzer`:

```bash
make test-fuzz
```

Or via CMake directly:

```bash
cmake -B build-fuzz -S . -DCMAKE_BUILD_TYPE=Debug -DLIBHISTO_ENABLE_ASAN=ON -DLIBHISTO_ENABLE_FUZZING=ON
cmake --build build-fuzz --parallel
ctest --test-dir build-fuzz -R "fuzz_" --output-on-failure
```

### Generating Corpus Seeds

Corpus seeds are deterministically generated by `generate_fuzz_corpus`:

```bash
./build-fuzz/tests/fuzz/generate_fuzz_corpus
```

### Continuous Fuzzing with LLVM libFuzzer

When building with Clang, targets can be linked directly with LLVM's libFuzzer:

```bash
CC=clang cmake -B build-fuzz -S . -DCMAKE_BUILD_TYPE=Debug -DLIBHISTO_ENABLE_FUZZING=ON -DLIBHISTO_ENABLE_ASAN=ON
cmake --build build-fuzz
./build-fuzz/tests/fuzz/fuzz_deserialize_binary tests/fuzz/corpus/binary
```
